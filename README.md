# Muse 注册与邀请码兑换教程

本文按 Muse 当前注册页面和产品实际流程整理。开放地区、年龄验证方式、邀请码入口和奖励规则可能调整，请以页面与 App 的实时提示为准。

## 注册账号

1. 打开 [Muse 注册页面](https://muse.ai/join)。如果页面显示暂未向你开放或只能加入等待名单，请按页面提示处理；不要填写不真实的地区、年龄或身份信息来绕过限制。
2. 选择邮箱注册，输入常用邮箱并获取验证码，按页面提示完成验证。
3. 注册过程中若要求年龄验证，选择页面实际提供且你可以完成的验证方式。验证选项可能因账号和地区不同而变化；如使用银行卡验证，请先阅读页面关于扣款、退款和账单的说明，不要提交不确定的支付信息。
4. 完成注册后，在 Muse 网页或 App 登录刚创建的账号。

请勿向他人提供登录验证码、密码或银行卡信息。若遇到错误提示，可稍后重试或查看 Muse 官方支持信息。

## 兑换邀请码

请在加入后的 **48 小时内**完成兑换：

1. 打开 Muse App，进入 **设置（Settings）**。
2. 在设置中找到 **通用（General）** 或 **使用情况（Usage）** 下的邀请码兑换入口。不同版本显示可能不同。
3. 选择 **兑换邀请码（Redeem invitation code）**，输入 `7F6MSA` 并提交。
4. 确认 App 显示兑换成功及奖励到账信息。

仅注册或复制邀请码不会完成兑换；需要在 App 设置中主动提交。若入口、时限或奖励与本指南不同，以 App 当前显示为准。
